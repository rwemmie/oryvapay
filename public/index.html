Built on PayPal

PayPal moves the money. OryvaPay decides if it should.

Every purchase runs through real PayPal APIs in the sandbox. The AI only decides between the two outcomes PayPal already supports: capture or void.

PayPalStep 1

PayPal authorizes

The buyer approves with the PayPal JS SDK. Funds are held, nothing is captured yet.

POST /v2/checkout/ordersintent: AUTHORIZE
OryvaPay AIStep 2

OryvaPay checks the order

Rule checks for every number, AI review for meaning: the PayPal order lines against the buyer's own words.

GET /v2/checkout/orders/{id}PASS · BLOCK · REVIEW
PayPalStep 3

PayPal captures or voids

A match is captured. A mismatch is voided and the hold is released. The buyer pays nothing for the wrong order.

POST /v2/payments/authorizations/{id}/capturePOST /v2/payments/authorizations/{id}/void
Each Intent Record keeps the PayPal order ID, authorization ID and capture ID, so the evidence lines up with the PayPal transaction.

How it works

Money is held, checked, then captured. Or released.

OryvaPay uses PayPal's authorize, capture and void flow. The buyer approves an authorization, so nothing is taken until the order PayPal received matches what the buyer actually wanted.
